> *Hash Set (unordered_set) là phiên bản đơn giản化的 của Hash Map: chỉ lưu khóa, không lưu giá trị — dùng để kiểm tra sự tồn tại trong O(1) trung bình.*

## Cấu trúc

Hash Set hoạt động giống Hash Map nhưng **không có phần giá trị**. Mỗi phần tử chỉ là một khóa duy nhất:

```
index = hash(key) % bucket_count
```

Bucket chứa danh sách các khóa có cùng chỉ số (chaining). Vì chỉ lưu khóa nên kiểm tra trùng lặp rất hiệu quả.

## Thao tác chính

- **insert(key)**: Băm key, thêm vào danh sách. O(1) trung bình.
- **find(key)**: Băm key, kiểm tra danh sách. O(1) trung bình.
- **erase(key)**: Băm key, xóa khỏi danh sách. O(1) trung bình.

Hash Set **không cho phép phần tử trùng lặp** — nếu insert lại key đã có thì không thay đổi gì.
