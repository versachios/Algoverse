> *Tree Set (std::set) lưu trữ khóa duy nhất trên cây đỏ-đen có thứ tự — giống Tree Map nhưng chỉ có key, không có value.*

## Cấu trúc

Tree Set sử dụng **c cây đỏ-đen** giống Tree Map, nhưng mỗi nút chỉ chứa một **key** (không có value). Key luôn được sắp xếp tăng dần theo traversal inorder.

## Thao tác chính

- **insert(key)**: Chèn key vào cây, cân bằng lại. O(log n).
- **find(key)**: Kiểm tra key có tồn tại trên đường đi từ gốc. O(log n).
- **erase(key)**: Xóa key, cân bằng lại. O(log n).
- **lower_bound(key)**: Tìm key lớn hơn hoặc bằng key cho trước. O(log n).
