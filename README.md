> **Thấy trước khi hiểu.**

Algo3D là nền tảng học thuật toán và cấu trúc dữ liệu **bằng trực quan hoá**, được xây dựng với mục tiêu biến những khái niệm trừu tượng — so sánh, đổi chỗ, đệ quy, chia để trị — thành thứ nhìn thấy được từng bước một, thay vì chỉ đọc pseudocode.

---

## ✨ Tính năng chính

- 🧩 **Mô phỏng 3D/2.5D từng bước** — Mỗi thuật toán là một generator function, chạy trực quan trên canvas thay vì chỉ là đoạn code tĩnh.
- 📖 **Lý thuyết đi kèm ví dụ** — Ý tưởng, độ phức tạp, ví dụ chạy tay và mini quiz cho từng bài học.
- 🎛️ **Player đầy đủ** — Play / Pause / Step / Reset / tua theo từng bước, tự nhập mảng đầu vào.
- 🕸️ **Đồ thị chủ đề 3D** — Bản đồ điều hướng thật trên trang chủ, không phải hình nền trang trí.
- 🔍 **Tìm kiếm & lọc** — Theo nhóm chủ đề và cấp độ (Cơ bản / Cấp 2-3 / Olympiad).

---

## 🎯 Đối tượng hướng tới

Algo3D dành cho **học sinh, sinh viên đang học thuật toán và cấu trúc dữ liệu**, đặc biệt là các bạn ôn thi học sinh giỏi tin học và các kỳ thi lập trình thi đấu (competitive programming).

---

## 🛠️ Công nghệ sử dụng

- **Frontend / Framework:** Next.js (App Router), React, Tailwind CSS
- **3D:** React Three Fiber, drei
- **State:** Zustand
- **Nội dung:** MDX
- **Language:** TypeScript

## 📑 Hướng dẫn sử dụng

1> Vào trang chủ, kéo xoay đồ thị 3D hoặc dùng ô tìm kiếm để chọn một chủ đề.

2> Nhấn vào node/card của thuật toán muốn học.

3> Đọc tab **Lý thuyết & Ví dụ** trước — ý tưởng, độ phức tạp, ví dụ chạy tay.

4> Chuyển sang tab **Mô phỏng trực quan**, tự nhập mảng đầu vào (tuỳ chọn).

5> Dùng Player để Play / Step / tua qua từng bước, đối chiếu với dòng code đang highlight.

## 📌 Trạng thái dự án

Algo3D đang trong quá trình phát triển tích cực. Giao diện, thuật toán và nội dung lý thuyết sẽ **liên tục được bổ sung**.

## 🤖 Định hướng phát triển (Roadmap)

- [x] 🔢 **Sorting cơ bản:** Bubble Sort, Selection Sort, Insertion Sort.
- [x] 🔎 **Searching cơ bản:** Linear Search, Binary Search.
- [ ] 👉 **Two Pointers / Sliding Window / Kadane's / Prefix Sum:** Nhóm thuật toán mảng 1 chiều, render 2.5D.
- [ ] ⚡ **Sorting O(n log n):** Quick Sort, Merge Sort, Heap Sort, Recursion & Backtracking.
- [ ] 🕸️ **Graph:** BFS, DFS, Dijkstra, A*, Union-Find/DSU.
- [ ] 🌳 **Tree:** BST, AVL Rotation, Segment Tree, Fenwick Tree.
- [ ] 🧮 **Dynamic Programming:** Knapsack, LCS, LIS.
- [ ] 📈 **Big-O Playground:** So sánh trực quan tốc độ tăng của các độ phức tạp phổ biến.
